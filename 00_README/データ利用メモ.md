### フラックス検算の注意

- 計数率 \(R = N / t\) は表とよく一致します。
- 熱中性子の \(\phi = R/(\varepsilon S)\) は表より約1%大きめになります（表内は \(R/\phi \approx 89\) で一貫）。
- MeV領域は \(\varepsilon S = 52.488\) をそのまま使うと表より大きくずれ、表内は \(R/\phi \approx 114\) で換算されています。
- **平均自由行程の比較では、公開表に載っているフラックス値を使う**のが安全です（換算定数の差が比には出にくいため）。

## 4. 平均自由行程の定義（前年と同じ）

大気中の宇宙線中性子フラックスが高度とともに増えるとして、

\[
\phi(h) \propto e^{h/\lambda}
\quad\Rightarrow\quad
\lambda = \frac{\Delta h}{\ln(\phi_\text{高}/\phi_\text{低})}
\]

大気深度 \(X\)（標準大気近似）では減衰長

\[
\Lambda = \frac{\Delta X}{\ln(\phi_\text{高}/\phi_\text{低})}
\]
