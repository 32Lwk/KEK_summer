## 図の読み方

| 要素 | 意味 |
|------|------|
| **緑の帯** | wall窓（191–764 keV）。**定義は従来どおり** |
| **灰の帯** | wall内で **ch<300**。低chノイズ疑いのため **積分から捨てた** |
| **黒破線 cut=300** | これより右だけを使う境界 |
| **cutより右の山** | 実測 ×(1/f)。D系 f=0.7690 / d系 f=0.7690 |
| **青の帯** | 764 keV より右の側帯 |
| **壁窓より左** | 表示のみ（積分に使わない） |

## 補正の式

`R_corr = N(ch>=300 ∩ wall) / f`

- f_large (D1/D2) = 0.769000
- f_small (d1/d2) = 0.769000
- 対象: **small-d（d1/d2）**
