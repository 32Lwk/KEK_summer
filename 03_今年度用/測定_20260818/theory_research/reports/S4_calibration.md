## 0. 結論サマリ

較正チェーン **黒鉛パイル(d1) → 管理棟2階 D1 → 地上 d2 → Linac3 D2** は、主窓 191–764 keV wall NET に基づき以下の ε×S [cm²] を伝播する。

| 段 | 転送 | ε×S_wall [cm²] | 支配的系統 [%] | 信頼度 |
|----|------|----------------|----------------|--------|
| S0 | d1 パイル絶対 | **74.2 ± 0.26** | 文献 Q ±8、dead 未補正 ±5、窓定義 — | 中 |
| S1 | D1/d1 @ 管理棟2階 | **134.6** (比 1.814) | **幾何比 3.41 との −47%**、窓依存 ±130、測定再現 ±3 | 低–中 |
| S2 | d2/D1 @ 地上 | **49.41** (比 0.367) | dead ±2、日差 ±5–10、PE スペクトル — | 中 |
| S3 | D2/D1 @ Linac3 | **153.6** (比 1.141) | **地上 NET≤0 で地点変更**、窓不一致 ±63、地点依存 ±23 | 低 |

**チェーン全体（d2 地上 φ まで）のランダム合成**: ≈ **±10%**（S0–S2 の統計・dead・日差）。  
**支配的系統（加法的）**: S1 の幾何欠落 **−47%**、S0 の Q 不確かさ **±8%**、S3 の Linac 代替 **+63%（窓依存）** — 平方和で **±50–70%** オーダーの絶対 φ 系統が残る。

**D1/d1 幾何比 1.81 vs 3.3（≈3.41）**: 側面積比 3.41 に対し実測 wall 転送比 1.814 は **53% しか拾わない**。同一 ε・側面支配なら εS(D1)≈253 cm² だが実際 135 cm² → **−47% の系統**。  
**D2 地上 wall NET 負**: 右側帯背景で NET = **−0.083 cps**（gross 0.421、peak ROI は +0.247 cps 有効）。Linac3 転送に迂回。**PE + 大径管 + 開空スペクトルで 764 keV 以降の連続が背景を上回る**のが直接原因。

## 1. 較正チェーンの定義とデータフロー

```
Am-Be + 黒鉛パイル (30/80 cm, 水平, 熱φ既知)
    │  εS_wall(d1) = 74.2 cm²
    ▼
d1 @ 管理棟2階  ──比 1.814──►  D1 @ 管理棟2階
    │                              │  εS_wall(D1) = 134.6 cm²
    │                              ▼
    │                         D1 @ 地上 (wall +0.413 cps)
    │                              │  比 0.367
    │                              ▼
    │                         d2 @ 地上 (wall +0.152 cps)
    │                              │  εS_wall(d2) = 49.41 cm²
    │                              │  φ_ground = 3.07×10⁻³ n/cm²/s
    │                              │
    │                         D2 @ 地上 ★ wall NET = −0.083 → 不可
    │                              │
    └──────────────────────────────┴── Linac3 で D2/D1 = 1.141
                                       εS_wall(D2) = 153.6 cm²
```

主窓: 191–764 keV、背景 = ピーク右側帯水平外挿（`mca_common.analyze_wall_window`）。  
絶対 φ: **φ = NET_CPS / εS_wall**（`build_flux_summary.py` L194–208, L8–10）。

## 2. 各転送段の定量評価

### 2.0 段 S0 — 黒鉛パイル → d1 絶対較正

**採用データ**（`calc_window_comparison.py` L207–224, `窓比較_計数率.csv`）:

| 距離 | wall NET [cps] | φ [n/cm²/s] | εS_wall [cm²] | dead [%] |
|------|----------------|-------------|---------------|----------|
| 30 cm | 1577.3 | 21.33 | 73.93 | 8.9 |
| 80 cm | 810.5 | 10.88 | 74.46 | 4.3 |
| **平均** | — | — | **74.20 ± 0.26** | — |

距離依存チェック: R₃₀/R₈₀ 観測 1.946 vs 理論 1.960 → **−0.7%**（`calc_detector_efficiency.py` L271–275 と整合）。

---

要因名: **Am-Be 源強度 Q の文献不確かさ**

物理メカニズム（式 + 参考文献）:  
φ(d) = (φ/Q) × Q × [(R+d_ref)/(R+d)]²。Q = 2.26×10⁶ n/s、φ/Q = 9.44×10⁻⁶ @30 cm（米内ほか, 保健物理 37(2) 118–127, 2002）。

今回条件への写像（地点/検出器/窓）:  
d1 @ 30/80 cm、wall 窓、水平・黒鉛あり。D1 @ 30/80 cm は dead 63/33% で**不採用**（`calc_detector_efficiency.py` L9–16）。

理論曲線の変化（functional form / 倍率）:  
εS ∝ 1/Q → Q が +8% なら φ 全体 **−8%**。

寄与見積もり（% および φ 倍率、地点別）:  
**±8%**（昨年も PHITS ε と 8% 差を「一致」としていた — `S0_last_year.md` §2.5）。全地点の絶対 φ に等方伝播。

不確かさ・信頼度（高/中/低 + 理由）:  
**中** — 文献値固定。源の再校正記録なし。

検証方法・追加実験/解析の提案:  
源強度の施設記録確認。³He プロポーショナル管の別距離（50 cm 等）追加測定。

---

要因名: **dead time 補正（パイル d1）**

物理メカニズム: R_true = R_obs / (1 − τ)。d1 パイル dead 4–9%。

今回条件への写像: `calc_detector_efficiency.py` は total モードで dead 補正するが、`calc_window_comparison.py` の wall CPS は **live 時間除算のみ**（L96–97）。

理論曲線の変化: dead 9% 未補正 → εS **+5%** 過大評価 → φ **−5%**。

寄与見積もり: **±3–5%**（30 cm 側が大）。80 cm は ±2%。

不確かさ・信頼度: **中** — dead は MCA REAL/LIVE から直接。

検証方法: wall 解析パイプラインに dead 補正を統一適用（S5 案件）。

---

要因名: **窓定義（wall vs peak ROI）— パイル段**

物理メカニズム: εS_wall / εS_peak = 1.477（d1、`検出器効率_壁効果191_764keV.csv`）。

今回条件への写像: 絶対較正は wall を採用。peak ROI 換算 εS = 50.22 cm²。

理論曲線の変化: peak 窓で規格化すると全 φ が wall 比 **×1.477**。

寄与見積もり: 窓選択のみで **+48%** の定義差（系統的・地点共通）。

不確かさ・信頼度: **高**（再計算で確定）。

### 2.1 段 S1 — d1 → D1 転送（管理棟2階）

**採用データ**（終夜測定、`D1効率_転送較正_壁効果.csv`）:

| 検出器 | ファイル | wall NET [cps] | peak ROI [cps] |
|--------|----------|----------------|----------------|
| d1 | d1_20260819_1520_管理棟2階 | 0.2014 | 0.1271 |
| D1 | D1_20260819_0832_管理棟2階 | 0.3652 | 0.5336 |
| **比 D1/d1** | — | **1.814** | **4.199** |

チェック（短時間 D1_1552）: wall 比 **1.873** → 終夜との差 **+3.3%**。

---

要因名: **D1/d1 幾何面積比 vs 実測転送比（1.814 vs 3.41）**

物理メカニズム: 円筒検出器の幾何比。側面積 S_side = 2πrL。  
d1: r=2.54 cm, L_active=31.0 cm → S=495 cm²。D1: r=4.8 cm, L=56 cm → S=1689 cm²（`detector_specs.py`, `calc_D1_efficiency_transfer.py` L81–82）。

今回条件への写像: 管理棟2階・同一地点・同一宇宙線場。幾何側面比 **3.410**、端面比 **3.571**。

理論曲線の変化: 幾何支配なら εS(D1) = 74.2 × 3.41 = **253 cm²**、φ(D1) = **−47%**（135/253）。

寄与見積もり:

| 比較対象 | 値 | 実測/期待 | 系統 [%] |
|----------|-----|-----------|----------|
| 側面積比 | 3.410 | 1.814/3.410 = 0.532 | **−46.8%** |
| 端面積比 | 3.571 | 1.814/3.571 = 0.508 | **−49.2%** |
| CONTEXT 記載 ≈3.3 | 3.3 | 1.814/3.3 = 0.550 | **−45.0%** |

**φ 倍率**: D1 で決定した全地点 φ が幾何期待より **≈0.53×**（一括スケール）。

不確かさ・信頼度: **低–中** — 幾何は確定、欠落 47% の物理起源は未同定（エネルギー依存 ε、角分布、大径管の γ 感度差が候補 — S3 引継ぎ）。

検証方法: PHITS で同一スペクトル・同一幾何の ε(E) 積分。D1 パイル飽和データは dead 補正後も R₃₀/R₈₀ 異常で直接較正不可。

---

要因名: **wall vs peak ROI 転送比の不一致（D1/d1）**

物理メカニズム: 大径 D1 は peak 窓で高エネルギー連続が相対的に強く、wall/peak 比 = 0.638（D1）vs 1.477（d1）。

今回条件への写像: peak ROI 転送（`calc_D1_efficiency_transfer.py`）比 **4.199**、wall 転送比 **1.814** → **2.31× 差**。

理論曲線の変化: peak 基準 εS(D1)=210.9 cm² vs wall 134.6 cm² → 同じ CPS から求める φ が **×1.57** 異なる。

寄与見積もり: 窓選択のみ **+57%**（D1 段）。以降の d2/D2 転送も窓に依存。

不確かさ・信頼度: **高**（数値は CSV 確定）。

---

要因名: **転送地点のスペクトル差（熱パイル vs 現場 MeV 混合）**

物理メカニズム: εS_wall は 191–764 keV 窓の積分効率。パイル = ほぼ熱中性子、管理棟2階 = 宇宙線 MeV + 捕獲混合（`S0_last_year.md` §3.2）。

今回条件への写像: d1 は S0 段で絶対確定済み。D1 転送は**同じ d1 管**の現場比のみ使用（パイル D1 は飽和除外）。

理論曲線の変化: 幾何 47% 欠落の主因候補。定量化は **±20–40%** 程度と推定（PHITS 未完了）。

寄与見積もり: 幾何欠落 −47% のうち **半分以上** がスペクトル・角分布効果の可能性（残りは dead/窓）。

不確かさ・信頼度: **低** — モデル計算待ち。

---

要因名: **管理棟2階 vs 地上 φ 比（昨年との矛盾）**

物理メカニズム: 絶対規格 A₀ = D1 地上 φ = 3.07×10⁻³。管理棟2階 = 2.71×10⁻³ → 比 0.88。

今回条件への写像: 昨年 d1 屋外/2階 = **0.76**（屋内高）、今年 D1 地上/2階 = **1.13**（屋外高）— `S0_last_year.md` §3.2, `phase0_reproduction.csv` L2–3。

理論曲線の変化: 転送比 1.814 と昨年比 1.81（今年/昨年屋外）の偶然一致（§0）は、**A₀ 自体が D1 大径管固有の +81% 系統**を含む可能性。

寄与見積もり: 屋外 φ 絶対値 **+81%** vs 昨年同型 d1（1.81×）。管理棟相対は **±15%** レベルで年度間符号反転。

不確かさ・信頼度: **中** — 昨年データは d1 のみで D1 比較不可。

物理メカニズム: d2 地上 dead = **1.70%**（`窓比較_計数率.csv` L32）。

寄与見積もり: **−1.7%**（d2 系全地点）。

不確かさ・信頼度: **高**。

---

要因名: **測定日差（D1: 8/19、 d2: 8/22）**

物理メカニズム: 宇宙線変動、気象、設置条件。

今回条件への写像: 同一地点「地上」だが **3 日差**。同時刻ペアなし。

理論曲線の変化: 宇宙線率日変動 **≈2–5%**（文献典型値）+ 設置 **±5%** → 合成 **±5–10%**。

寄与見積もり: d2/D1 比 **±5–10%** → φ_ground **±5–10%**。

不確かさ・信頼度: **中** — 同地点 peak 比較（D1 433 vs d2 54 cps）のみ。

---

要因名: **PE 付き d2 vs 裸管 D1 のスペクトル応答差**

物理メカニズム: d2 は PE 筒 5 cm 減速（`detector_specs.py`）。D1 は裸管。同一 φ でも MeV 成分の検出効率が異なる。

今回条件への写像: wall/peak 比 — D1 地上 0.95、d2 地上 **2.82**（`phase0_reproduction.csv`）。

理論曲線の変化: 転送比 0.367 は wall 窓限定。peak 転送（`d2効率_転送較正.csv` ROI 比 0.124）だと εS(d2)=26.2 cm² → 同 NET から φ が **×1.89** 高くなる。

寄与見積もり: 窓依存 **±50–90%**（peak vs wall）。地点依存（PF で d2 wall/peak = 6.84）。

不確かさ・信頼度: **低–中** — S3 で ε(E) 積分要。

---

要因名: **D2 地上 wall NET≤0 による転送地点の変更**

物理メカニズム: NET = ∫₁₉₁–₇₆₄ S(E) dE − BG_right。BG が gross を上回る。

今回条件への写像: D2 絶対 φ は **Linac3**（t_eq=300 cm, X=690 g/cm²）で D1 比から決定。地上 A₀ とは独立。

理論曲線の変化: 地上と Linac でスペクトルが異なる → D2/D1 比が **地点依存 +23%**（peak: 0.570→0.699）。wall 比 1.141 は peak 比の **+63%**。

寄与見積もり:

| 効果 | % |
|------|---|
| 地上→Linac 地点変更（peak 基準） | **+23%** |
| wall vs peak @ Linac | **+63%** |
| D2 φ(Linac) vs D1 φ(Linac) 整合 | 0%（転送构造） |
| D2 φ(Linac) vs d2 φ(地上) 相対 | Linac/d2 = 0.084×（深度効果、較正外） |

不確かさ・信頼度: **低** — D2 絶対スケールは Linac 一点に依存。

検証方法: D2 地上で (i) 左側帯背景、(ii) peak ROI 絶対較正（`calc_d2_efficiency_transfer.py` は ROI@地上 = 120.2 cm²）、(iii) total 積分窓。γ 除外・dead 補正（S5）。

---

要因名: **D2/D1 窓不一致（Linac3）**

物理メカニズム: D2 wall/peak = 0.963、D1 wall/peak = 0.589 @ Linac3（`phase0_reproduction.csv`）。

今回条件への写像: wall 転送比 1.141 vs peak 0.699。

理論曲線の変化: peak 基準 εS(D2)=120.2 cm²（`d2効率_転送較正.csv` は D2 だが同系）vs wall 153.6 cm² → **+28%** φ 差。

寄与見積もり: **±28–63%**（窓選択）。

不確かさ・信頼度: **中**（再計算可、物理解釈は S3）。

## 5. 較正チェーンが深度解析への影響
