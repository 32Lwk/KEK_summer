### 2.2 直線背景が破綻する物理

- 壁効果窓（191–764 keV）の**右側連続**は、(n, p) 反跳 proton・γ コンプトン由来の**非物理背景**（CONTEXT §データ品質）。
- 左右直線は「左側低エネルギー側帯」と「右側連続側帯」を結ぶため、深い地点・PE 付き検出器で**背景が積分窓全体を上回り NET<0** となる（D1 linac: L=−1.90 CPS）。
- **右側帯水平**は右連続のみを背景とし、物理的には「ピーク下の連続成分」を差し引く近似。高速成分が右側帯自体を持ち上げる地点（BT, 地上 D2）では NET が小さく/負になりうるが、再解析では BT・D2 地上とも正 NET を得た。

## 3. dead time 補正

### 3.1 測定記録.csv の dead_pct

- 定義: `dead_pct = 100 × (1 − LIVE_TIME/REAL_TIME)`（`_build_mca_xlsx.summarize` と同一）。
- SN1715（D1/D2）: 0.08–0.30%（終夜長時間測定）。ch0 ADC オーバーフロー（32 cps 級）は **dead_pct に含まれない**。
- SN2162（d1/d2）: 0.04–2.7%（短い real 時間測定で 1.7–2.7%）。

### 3.2 補正の適用と注意

- 補正式: `CPS_corr = CPS_meas / (1 − dead_pct/100)`。
- MCA の **LIVE_TIME は dead 時間を除いた live 積算**のため、厳密には `counts/live` は既に dead 補正済み。**追加の `/ (1−τ)` は保守的上振れ**（最大 2.7% @ d2 PF）。
- CONTEXT の「D1 系 8–15%」は **ch0 オーバーフロー率**（`ch0_cps / 計数率`）を指す可能性が高く、live/real dead とは別指標。**絶対 φ 規格への ch0 系統は S4/S3 に委譲**。

### 3.3 dead 補正の影響（|Δ|>1% のみ）

|--------|------|---------|-----------|----------|---|

## 6. 要因別テンプレート（CONTEXT 形式）

### 6.1 右側帯背景 vs 直線背景

```
要因名: 壁窓背景定義（右側帯 vs 左右直線）
物理メカニズム: NET = Σ_counts(191–764 keV) − b×N_win。b=右側連続側帯平均（水平）または左右側帯直線。高速反跳・γ が右側帯を持ち上げ b が過大 → NET 過小/負。
今回条件への写像: 全 wall 窓・全検出器。D1/D2 大径管で直線背景 64% が NET≤0。
理論曲線の変化: φ_wall 直接入力。直線採用時 PF@D1 は φ→負（物理不可）→ 棄却。
寄与見積もり: 背景法差 sys_bg_err = 0–0.21 CPS（φ 比 0–40% @ 深遮蔽）。地上 D1: 直線/右 = 0.55 → φ 45% 過小。
不確かさ・信頼度: 中 — 右側帯は現行主値だが物理背景分離は不完全（S3 委譲）。
検証: PHITS スペクトルから b(E) を生成し側帯平均を検証。γ 除去測定。
```

### 6.2 dead time

```
要因名: MCA dead time（live/real）
物理メカニズム: τ = 1 − LIVE/REAL。CPS_true ≈ CPS_meas/(1−τ)。非パラライザブル近似。
今回条件: d2 長時間 1–3%。D1 live/real ≈0.1%（ch0 飽和は別系統）。
理論曲線: φ 比 ±3%（d2）。D1 可忽略。
寄与: d2 PF +2.5%; d2 地上 +1.7%。
信頼度: 低–中 — LIVE_TIME 二重補正リスク。ch0 飽和未込み。
検証: パイル飽和ラン除外。ch0 除く計数率との整合（S4）。
```

### 6.3 PF ファイル選択（d2）

```
要因名: d2 PF 測定日・ゲイン異常
物理メカニズム: ゲイン drift → peak_ch 505（8/20）vs 396（8/22）。764 keV 校正破綻 → 窓幅・背景 ch 定義が無効。
写像: PF@d2 のみ。8/20 棄却、8/22 採用。
理論曲線: φ_PF(d2) が 8× 変動。採用値 4.12×10⁻³（旧理論 19× 乖離の起点）。
寄与: ファイル選択 870%。ゲイン 8/20 使用時 PF/地上 比 0.15（実際 1.31）。
信頼度: 高 — peak_ch・ROI NET・右側帯 mode が明確に異常。
検証: 8/20 d2 再測定不可。8/22 を固定。D1 PF 8/20 はアンプ取り違えのため `D2_20260822_115234_PF` 参照で rebin 補正（peak 242→388、wall 0.235 cps）して採用。
```

### 6.4 負 NET 回復（BT, D2 地上）

```
要因名: 生スペクトル再解析による NET 符号回復
物理メカニズム: 旧表（`フラックス_地点まとめ.csv`）と生 MCA 再計算の不一致。右側帯 shift（ピーク裾回避）の適用差。
写像: D1@BT 0.0539 CPS（旧 −0.049）; D2@地上 0.0915 CPS（旧 −0.083）。
理論曲線: BT φ_wall 有限化。D2 地上 εS 転送可能に。
寄与: BT d2 φ 4.0×10⁻⁴ 確定。D2 絶対規格の起点回復。
信頼度: 中 — 測定記録.csv と一致。要 S6 PHITS 突合。
```
