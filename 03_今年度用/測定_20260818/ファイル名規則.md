# MCA ファイル名規則

1本の測定は、次の4つの部品をアンダースコア `_` でつなぐ。

```text
日付_時刻_場所_検出器.mca
```

例:

```text
20260819_0832_管理棟2階_D1.mca
│        │    │        │
│        │    │        └ 検出器（D1 と d1 は別物）
│        │    └ 場所
│        └ 終了時刻（時分、24時間）
└ 終了日（西暦8桁）
```

同じ名前の `.csv`（中身は `channel,counts`）も付ける。

## 各部品

| 部品 | 書き方 | 注意 |
|------|--------|------|
| 日付 | `YYYYMMDD` | 測定が **終わった日** |
| 時刻 | `HHMM` | 測定が **終わった時刻**。MCA の開始時刻＋リアルタイムを、分に四捨五入（秒が30以上なら繰り上げ） |
| 場所 | 下の語だけ | 日本語。linac だけ英語。空白や全角文字は使わない |
| 検出器 | `D1` / `d1` / `d2` など | **大文字 D と小文字 d は別の検出器**。書き換えない |

### 場所に使える語

| 書く文字 | 意味 |
|----------|------|
| 管理棟1階 | 管理棟 1 階 |
| 管理棟2階 | 管理棟 2 階 |
| linac | linac 建屋 |
| 放射線棟BT | 放射線棟 BT |
| 地上 | 屋外地上 |

放射線棟に 2 階はない。`放射線棟2階` とは書かない。

計数率の桁が違うときは、まず検出器（D か d か）を疑う。場所の差と混ぜない。

同じ終了時刻・同じ場所で `D1` と `d1` だけが違う名前は、macOS では同じファイル扱いになって共存できない。そのときだけ時刻に秒を足す。
