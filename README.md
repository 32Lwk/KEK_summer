## 昨年データの要点（すぐ使うならここ）

| 項目 | 内容 |
|------|------|
| 出典 | KEKサマーチャレンジ 9班・公開用実験結果表 |
| 測定量 | 熱中性子／MeV領域の計数・フラックス |
| 測定地点 | 管理棟1・2階、プレハブ、筑波山、白根山（屋外は空欄） |
| 推奨解析結果 | **MeV・管理棟2階→白根山：λ ≈ 1.28 km、Λ ≈ 141 g/cm²** |

### 計算式

\[
\lambda = \frac{h_2 - h_1}{\ln(\phi_2/\phi_1)},\qquad
\Lambda = \frac{X_1 - X_2}{\ln(\phi_2/\phi_1)}
\]

### 標高の仮定（要確認）

| 地点 | 仮定標高 |
|------|----------|
| KEK（管理棟・プレハブ） | 30 m |
| 筑波山 | 877 m |
| 白根山（草津白根山として） | 2160 m |

## 今年度の研究テーマ（続き）

昨年度の高度依存の続きとして、**標高 0 m より低い領域**の振る舞いを調べる。

- **KEK地質に基づく地下予測（Excel）**: [`03_今年度用/KEK地下測定_地質予測.xlsx`](03_今年度用/KEK地下測定_地質予測.xlsx)
- 詳細リサーチ: [`03_今年度用/リサーチ_標高0m以下の予測.md`](03_今年度用/リサーチ_標高0m以下の予測.md)
- 予測表CSV: `03_今年度用/予測_負標高_大気.csv`, `03_今年度用/予測_地下覆土.csv`
- 予測スクリプト: `03_今年度用/predict_below_sea_level.py`

**要点**: 「標高だけ負」では変化は緩やか。**地下・覆土**なら昨年度の Λ≈141 g cm⁻² で急減衰を予測でき、今年度の本命検証になる。

## 今年度への使い方（最短）

1. `01_前年データ_9班/tables/` の CSV を比較用の基準データとして読む  
2. `03_今年度用/リサーチ_標高0m以下の予測.md` で仮説を確認  
3. `03_今年度用/template_測定記録.csv` に今年度の測定を記入（覆土厚・密度も記録）  
4. `03_今年度用/calc_mean_free_path.py` / `predict_below_sea_level.py` で比較  
5. グラフ・まとめは `02_解析/宇宙線中性子_平均自由行程.xlsx` を参照・複製

詳細な注意点は [`00_README/データ利用メモ.md`](00_README/データ利用メモ.md) を見てください。
