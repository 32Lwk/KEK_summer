## 昨年データの要点（すぐ使うならここ）

| 項目 | 内容 |
|------|------|
| 出典 | KEKサマーチャレンジ 9班・公開用実験結果表 |
| 測定量 | 熱中性子／MeV領域の計数・フラックス |
| 測定地点 | 管理棟1・2階、プレハブ、筑波山、白根山（屋外は空欄） |
| 推奨解析結果 | **熱中性子・管理棟1階→白根山：λ ≈ 1470 m**（Λ ≈ 147 g/cm²） |

### 計算式（昨年と同じ）

\[
\lambda = \frac{\Delta h}{\ln(\phi_2/\phi_1)}\quad[\mathrm{m}],\qquad
\Lambda = \rho_\mathrm{air}\,\Delta h\,/\,\ln(\phi_2/\phi_1)\quad[\mathrm{g\,cm^{-2}}]
\]
（空気は一様密度 \(\rho_\mathrm{air} = 1.00\times10^{-3}\,\mathrm{g\,cm^{-3}}\)。\(\Delta h = 2000\,\mathrm{m}\)。\(\lambda\,[\mathrm{m}]=10\,\Lambda\)）

標準大気の \(X(h)\) を使うと熱中性子は約 1730 m になるが、それは昨年の定義ではない。

### 標高の仮定（平均自由行程の計算）

| 地点 | 昨年の計算での標高差 |
|------|----------------------|
| KEK（管理棟1階＝基準） | 0 m |
| 筑波山 | 877 m |
| 白根山 | 2000 m |

## 今年度の研究テーマ（続き）

昨年度の高度依存の続きとして、**標高 0 m より低い領域**の振る舞いを調べる。

- **KEK地質に基づく地下予測（Excel）**: [`03_今年度用/KEK地下測定_地質予測.xlsx`](03_今年度用/KEK地下測定_地質予測.xlsx)
- 詳細リサーチ: [`03_今年度用/リサーチ_標高0m以下の予測.md`](03_今年度用/リサーチ_標高0m以下の予測.md)
- 予測表CSV: `03_今年度用/予測_負標高_大気.csv`, `03_今年度用/予測_地下覆土.csv`
- 予測スクリプト: `03_今年度用/predict_below_sea_level.py`

**要点**: 「標高だけ負」では変化は緩やか。**地下・覆土**なら昨年度の熱中性子 λ≈1470 m で急減衰を予測でき、今年度の本命検証になる。
