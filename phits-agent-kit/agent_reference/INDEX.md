# PHITS Agent Reference — Index

Entry point for AI agents. Use **targeted searches**; do not load
every file at once. Files are grouped by category below.

These Markdown files hold only what is not directly readable from the
source folders: manuals, extracted slide/document text, and catalogs.
PHITS input (`.inp`), output, and other plain-text files are **not**
duplicated here — read them directly from the `sample/`, `recommendation/`,
`lecture/`, and `utility/` folders under the PHITS root.

NotebookLM / RAG users: upload the merged bundles in the sibling
`knowledge_base/` folder instead.
