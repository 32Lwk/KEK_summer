Format of PHITS input
Calculation conditions are specified by a text file
Basic format
keyword（parameter） = value or character
[ Section Name ] ←start of the section
An input file consists of several sections
(“space” means nothing)
parameter1    parameter2    parameter3  …
Parameters are separated by “space”
Up to 200 characters in one line
Lines starting with more than 6 spaces are successive lines
or
Parameters can be given in mathematic equations: e.g. 1.0+exp(-2.0)
SPEAKER_NOTES:
Here is the format of the PHITS input file.
All calculation conditions are described by text input.
The input file consists of multiple sections, and the section name in square brackets indicates the beginning of the section.
The basic format of the input file is represented by a keyword or parameter equal to a numerical value or a character string.
At this time, the space is ignored.
Alternatively, it is represented by a list of numbers or character strings.
At this time, please note that it is separated by spaces, up to 200 characters can be put on one line, and more than that, it should be on the continuation line, and the continuation line should have 6 or more spaces at the beginning of the sentence.
It is also possible to give parameters as mathematical formulas.

--- SLIDE 05 ---
PPTX_FILE: phits-lec01-en.pptx
SLIDE_TEXT:
Input support command
*Sections can be placed in an arbitrary order
[         ]off
    skip this section
qp:
   skip from this line to the next section
q:
   equivalent to [end] section
Comment marks
     C in the first 5 column of a line (except [material] section)
     $ and # in the middle of a line
      (but avoid using # in the [cell] and [surface] sections)
     →$ is recommended
Characters are case insensitive
SPEAKER_NOTES:
Here is the input assistance.
By turning off the section name, you can skip the section.

When you write “qp colon“ at the line head, reading of parameters is skipped from this line to the next section.
“q colon” is equivalent to the “End section”.
Any input information written below the “End section” is ignored.

To add a comment in an input file,
please add “C” in the first 5 columns of a line except the [material] section
and $ and # in the middle of a line.
But please avoid using # in the [cell] and [surface] sections.

Considering the above, we recommend using the dollar mark for comment marks.

#all function
It is necessary to define even empty regions (such as void or air) in the same way as other regions (avoiding double-definition).
Using #all is convenient because it automatically subtracts all defined regions*. #all can only be used once in a single input.
In the case of lec01.inp, #all is converted to “#100  #101”.
If the number of subtract regions becomes very large, it may lead to insufficient memory, reduced calculation speed, or errors.
In the cases of complex geometry with approximately 20 or more objects, it is preferable to explicitly define subtract regions using #(surface numbers) instead of using #all.

SPEAKER_NOTES:
Now, let me explain the hash-mark all function.
Even regions that contain nothing such as vacuum or air must be defined in a way that avoids double definitions with other regions.
The hash mark all operator automatically subtracts all previously defined regions, which makes it very convenient.
However, keep in mind that you can use only one hash mark all in a single input file.
In the case of the file rec01.inp, the hash mark all operator is internally expanded by the program into #100 and #101, subtracting those regions automatically.
If too many regions are excluded in this way, the program may run out of memory, which can slow down the calculation or even cause errors.
Therefore, for complex geometries with around 20 or more regions, it is recommended not to use hash mark all.
Instead, it is better to explicitly specify the regions to be excluded, for example by using expressions such as #(surface numbers).

物質の定義方法
単一元素の場合（例：金 19.32 g/cm3）
	mat[1]  Au   -19.32
各元素の質量密度g/cm3が分かる場合（例：人体軟組織）
	m100  H -0.101  C  -0.111  N  -0.026  O  -0.762
元素数比が分かる場合（例：空気、窒素８０％、酸素20%）
	mat[10]  N   80.0      O   20.0
化学式が分かる場合（例：ポリエチレン、C2H4）
	m5  C   2        H   4
[material]セクションにおいて、mat[1]もしくはm1のような形式で定義する
書式は「元素記号 密度 元素記号 密度…」（スペース区切り）
密度を正の値で与えた場合は元素数密度（1024個/cm3）
密度を負の値で与えた場合は質量密度（g/cm3）
密度を相対比で与え、その絶対値を[cell]で定義することも可能
水やコンクリートなど、よく使う物質は既定物質としてより簡単に設定可能（基礎実習III参照）
→特に元素数密度比でしか組成が分からない物質を定義する際に便利！
SPEAKER_NOTES:
物質は、[マテリアル]セクションにおいて、マット1もしくはm1のような形式で定義します。
その書式は元素記号 密度 元素記号 密度の繰り返しで、スペース区切るです。
密度を正の値で与えた場合は元素数密度でその単位は１０の２４乗個 per立方センチメートルで、負の値で与えた場合は質量密度でその単位はグラム per 立方センチメートルです。 密度を相対比で与え、その絶対値を[cell]セクションで定義することも可能で、このやり方は、例えば水など、特に元素数密度比でしか組成が分からない物質を定義する際に便利です。
