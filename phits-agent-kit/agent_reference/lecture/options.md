How to use
[ Transform ]
*Trn      X0  Y0  Z0        XC  YC  ZC     A1  θ1     A2  θ2     A3  θ3      M
Order of translation & rotation
M=3：rotation → translation
M=-3：translation → rotation
Translation component
*Axis (Ai) & angle (θi) for ith rotation
ID number
Example 1: *tr1    0.0 0.0 5.0      0.0 10.0 0.0     2 45.0     3 -60.0      0 0.0      3

Example 2：  tr1    0.0 0.0 -5.0      0.0 0.0 0.0     1  pi/4       0 0.0       0 0.0      -3
Angle unit option
with *: degree
without *: radian
To define a transformation, an ID and 13 parameters are needed.
1, Define a [transform] section
2, Use this [transform] by setting trcl=n in [cell], [source], etc.
Center of rotation
Rotating at the center of (0 10 0) around Y-axis by 45 deg and Z-axis by -60 deg, and then translating along +Z-axis by 5 cm.
Translating along +Z-axis by 5cm, and then rotating at the center of (0 0 0) around X-axis by 45 deg. (Note that when M=-3, direction of translation is opposite to that in M=3)
*Ai=1,2, & 3 indicate the rotation around X, Y, & Z axes, respectively

Electro magnetic field instruction
reg: ID of cell where electro/magnetic field is defined
elf: strength of electric field in kV/cm
mgf: strength of magnetic field in kG
trcle: electric field transform ID
trclm: magnetic field transform ID
1, Define [electro magnetic field] section
2, Set ielctf=1 in [parameters] to activate [electro magnetic field] .
*Electric field and magnetic field can coexist, except for quadrupole magnetic field and electric field
* Default field type is dipole
[Electro Magnetic Field ]
    reg      elf    mgf     trcle trclm
    1        10.0    -5.0     3      3
    2       -10.0    5.0      1      2
    3         0.0    -10.0    0      0
[electro magnetic field]
Direction of Fields
+Y-axis for magnetic field
→positive charged particles go to the negative direction of X-axis when they go to the positive direction of Z-axis
+X-axis for electric field
→positive charged particles are attracted to +X direction

What is “Counter” in PHITS?
Each particle has its own “Counter” number to identify what it has experienced, such as entering, exiting from, reacting in, and reflected in a certain region. “Counter” serves as an event logger in PHITS.
To investigate the origin of the tallied particles
e.g. Where is this tallied particle from ?
Tally with scoring particles having only counter in a certain range
(e.g. c ≥ 1)
When a particle reacts in a region, counter = counter +1.
X
c = 1
c = 0
* From Version 3.36, particle transport can be terminated by the counter cut-off function by setting ctmin or ctmax in [parameters].

4重極磁場の使用方法
[electro magnetic field]
reg: 磁場を置く領域
typm: =2; 2重極磁場(デフォルト),
          =4; 4重極磁場
gap: 磁石間の距離の半分[cm]
（2重極の時は使わないが何らかの値を入れる）
mgf: 磁場の強さ[kG]
trclm: 磁場のTransform番号
elf: 電場の強さ[kV/m]
trcle: 電場のTransform番号
2重極磁場はy軸の正方向
→正の荷電粒子がz軸方向に進む時、
 x軸の負の方向に動く。電場と混合可

4重極磁場は
→正の荷電粒子がz軸方向に進む時、
 x軸方向に収束、y軸方向に分散する
（z軸を中心軸とし無限に4重極磁石を配置した時の磁場として定義されるため、体系にあわせて座標変換が必要。）
電場と混合不可
＊電子・陽電子に関しては、EGS5を使用する場合のみ使用可能。
