1. General Description
  Instruction and sample input files for using SimpleGEO as a PHITS geometry generator

2. Requirement
  SimpleGEO: An interactive solid modeler which allows for flexible and easy creation
             of the models via drag & drop, as well as on-the-fly inspection.
             This software works only in Windows.
             Plugin package must be also installed, if you want to visualize the
             PHITS tally output with xyz mesh in SimpleGEO
             Download site: http://theis.web.cern.ch/theis/simplegeo/

3. Procedure
  1. Create 3D geometry such as 'doll.dat' using Simple GEO.
     You have to make a 'Blackhole' region at the outer region of the geometry.

  2. Select 'File -> Export -> PHITS' in SimpleGEO, then
     it exports the geometry to PHITS input format using [cell] & [surface] sections.

  3. Make PHITS input file except for [cell] & [surface] sections, and
     include the exported file such as 'doll.pht' in the input file
     (e.g. 'infl: {doll.pht}' written in the line 80 of 'SimpleGEO.inp')
     You have to write 'file=file name' at the 1st line of the input file.
     You have to prepare [material] section by yourself.

  4. Execute PHITS using the input file

  5. Visualize PHITS tally output with xyz mesh in SimpleGEO (Optional)
   5-1 Select'Macros -> Load Plugins -> DaVis 3D -> Load selected Plug-Ins' in SimpleGEO
       You have to install plugins before this procedure
   5-2 Press 'DaVis3D' (sometimes it is hidden)
   5-3 Select PHITS tally output with xyz mesh, and press 'Load data'
       You have to set the file extension to '.out'
   5-4 Select 'XY-plane', 'YZ-plane', 'ZY-plane' and visualize the result

4. Important notices
  SimpleGEO export the geometry to PHITS input format using Macrobodies,
  but current version of PHITS cannot handle the macrobodies of
  Cone, Torus, Ellipsoid and Elliptical Cylinder.
  We are planning to include these functions in PHITS in the early 2013.

  SimpleGEO can read PHITS input file, and import its geometry, except for
  that using lattice and replica (lat and like commands).
  You have to set the extension of PHITS input file to '.pht'

5. Acknowledgement
  Import and export functions of SimpleGEO to PHITS input format are developed
  by the courtesy of Dr. Chris Theis @ CERN.

List of Contents

  SimpleGEO.jpg: Screen capture of SimpleGEO combined with deposit-xy.out

1.概要
  幾何学形状作成ソフトウェアSimpleGEOを用いて作成したジオメトリを
  PHITSで読み込むための手順とそのサンプルインプットファイルです。

2.必要ソフトウェア
  SimpleGEO: GUIベースで3次元体系を構築する登録制(無料)のWindowsアプリケーションです。
             (Linux, Macでは動作しないので,仮想Windows環境を導入する必要があります)
             PHITSの結果を取り込むためには,plugin packageもインストールする必要があります
             ダウンロードサイト http://theis.web.cern.ch/theis/simplegeo/

3.使い方
  1. 'doll.dat'のような体系をSimpleGEOで作成する。
     その際,一番外側にBlackhole領域を作る必要があります。

  2. SimpleGEOで,File -> Export -> PHITSとして,
     PHITSの[cell]と[surface]セクションを出力する(doll.pht)。

  3. [cell]と[surface]セクションを除いたPHITS入力ファイル(SimpleGEO.inp)を
     作成し,手順1で作成したExportファイルをインクルードする
     (SimpleGEO.inpの80行目,infl: {doll.pht}を参照)
     その際,inflコマンドを使うため,必ずインプットファイルの
     1行目にfile名と書いておく必要があります(file=SimpleGEO.inp)。
     また,[material]セクションに関しては,自分で用意する必要があります。

  4. PHITSを実行する

  5. PHITSのmesh=xyzを使ったタリーの結果をSimpleGEOで表示する(オプショナル)
   1SimpleGEOで,Macros -> Load Plugins -> DaVis 3Dを選択 -> Load selected Plug-Ins
     とする。その際,plugin packageをSimpleGEOをインストールしたフォルダに
     入れておく必要があります。
   2Automatic Updateの隣にある'DaVis3D'ボタンを押す(隠れている場合があるので注意)
   3File nameでXYZメッシュタリーの結果を選択し,Load dataボタンを押す。
    (拡張子を.outにしないとPHITS出力と認識しないので注意)
   4XY-plane, YZ-plane, ZY-planeを選択して結果を可視化する

4.注意点など
  SimpleGEOは,基本的にマクロボディの機能を使ってPHITS形式に出力しますが,
  現versionのPHITSは,Cone, Torus, Ellipsoid, Elliptical Cylinderに対応していません。
  これらの形状への対応は,2013年春頃を予定しています。

  SimpleGEOは,Import機能を使ってPHITS形式で書かれたジオメトリを読み込むことができます。
  ただし,LatticeやReplica(latやlikeコマンド)を使ったジオメトリは読み込めません。
  また,PHITS入力ファイルの拡張子は*.phtとする必要があります。

5.謝辞
  SimpleGEOのPHITS import & export機能は,
  CERNのChris Theis博士のご厚意により作成されています。
END_BASIC_TEXT
